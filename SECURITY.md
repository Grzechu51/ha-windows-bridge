# Security Policy

## Supported versions

Security fixes are provided for the newest published version of HA Windows Bridge.

## Reporting a vulnerability

Please do not publish credentials, private MQTT topics or exploit details in a public issue. Use GitHub's **Security** → **Report a vulnerability** option for this repository. Include the affected version, reproduction steps and the expected impact.

Never include a real MQTT password or a configuration file containing private network details. Replace them with sample values before attaching logs or screenshots.
